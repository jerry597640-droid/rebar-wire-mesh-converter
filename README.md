# 鋼筋與鋼線網互換分析工作台

離線使用：解壓縮後，以 Chrome、Edge 或其他現代瀏覽器開啟 `index.html`，不需安裝、不需伺服器。頁面內「操作與依據」含完整欄位定義、資料來源、公式、修正說明與網路查核來源。

## 功能

- 鋼筋 → 鋼線網、鋼線網 → 鋼筋，X/Y 兩方向分別換算。
- 沿用提供 VB 程式的名義鋼筋面積、最終最小配筋公式與原規格間距範圍。
- 支援不同方向不同線徑、自訂鋼線網尺寸、網片寬長記錄。
- 尺寸庫本機儲存、JSON 匯入／匯出，跨電腦可攜。
- 即時顯示提供／需求比、理論最大間距、候選規格及完整計算過程。
- 桌面工作台與手機版面，手機底部可直接跳到結果。
- 瀏覽器列印／另存 PDF。

## 計算範圍

等值原理：As原 × fy原 = As目標 × fy目標。

目標需求取等值鋼量及所選最小配筋量的大值。原程式模式不是完整現行規範設計；板、牆、耐震構件需依適用規範另外確認最小鋼量、最大間距、裂縫、彎矩、有效深度、錨定、搭接與保護層。

全部間距使用 mm，厚度使用 cm，強度使用 kgf/cm²。500 MPa 約為 5098.58 kgf/cm²，不是精確等於 5000 kgf/cm²。

## 附件程式修正

- 統一原先報表前後不一致的最小配筋比。
- 消除理論間距的 Integer 隱式取整；以未四捨五入數值判定。
- 使用 Math.PI，保留附件的鋼筋名義面積表。
- 原規格候選依雙向總鋼量排序；自訂線徑及不同線徑使用原 22 組間距作參考，不保證廠商供貨。
